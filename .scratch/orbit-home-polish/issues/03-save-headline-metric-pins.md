# 03 — Choose and save headline metrics

**What to build** Start with the four agreed defaults, then pin or replace metrics and see those choices after relaunch.

**Blocked by** [01 — Give engagement totals and history the lead](01-refine-the-home-layout.md)

**Status** complete

- [x] The owner can pin, replace, or remove metrics through Home and can save up to four distinct metrics.
- [x] Choices persist in the local workspace across relaunches. Existing workspaces get the default pins.
- [x] Selecting a headline metric or selecting from the chart menu controls one chart. Selecting a chart metric leaves pins unchanged.

Verified default and edited pins in the browser preview, rejection of invalid selections in the workspace tests, and a full Electron relaunch with saved pins.
