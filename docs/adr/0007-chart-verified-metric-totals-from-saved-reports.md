# Chart verified metric totals from saved reports

Saving an on-demand engagement report updates the metric totals on Home and supplies dated observations for its charts. Each metric displays its numeric total and retains the date or reporting period, the source, and its scope, such as Facebook Page post views or X reply views. Figures carried forward keep their last verified date, and each trend uses comparable verified observations.

Selecting a chart point opens the saved report with its supporting figures and post links where available. Discord is a reporting-only source for the first version, with server membership and the owner's invite contribution on Home and in the weekly report. Discord invite-use counts are labeled **Your invite uses** and retain their recorded coverage.

## Home comparison rule

For a period total, show the raw value and its reporting window. Show a change badge only when both verified observations have the same metric scope and comparable windows. Use equal known durations for V1. For example, show a ten-day view total and a four-day view total with their own date ranges and omit the change badge between them. Keep the original observation date when carrying a value forward.

Plot both verified totals as individual points with their date ranges. Connect consecutive points only when their windows are comparable. Each point opens its own saved report, including points on either side of a break.

Point-in-time counts can show a change between verified readings of the same scope even when the time between reports varies. The displayed reporting window describes the underlying measurement period. The verification date records when the figure was checked.
