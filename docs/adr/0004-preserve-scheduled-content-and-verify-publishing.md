# Preserve scheduled content and verify uncertain publishing outcomes

Scheduling captures the caption and media for each destination, and later changes are made on the scheduled post. After a publishing timeout, check for the published post before retrying and save its link when found. Show Verify publication when the outcome is still uncertain so the owner can check the destination.

When an attached file comes from Drive, save a local copy at scheduling time and use that copy for publishing. A Drive URL entered in the caption is part of the caption.
