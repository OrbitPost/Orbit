# Compare weekly engagement on demand

A weekly engagement report starts only when the owner presses the report button in Analytics or asks the agent in chat. The first saved report establishes the baseline. Subsequent runs compare current metrics against previous values and group results by platform. A request without explicit dates covers activity from the previous report cutoff through the current check in Asia/Bangkok.

When an account needs sign-in, show **Reconnect** and **Copy link** and keep checking the other accounts. If neither action is used within five minutes of the prompt appearing, finish the report with that account's last verified figures and date. The first click or copy starts a separate five-minute window to finish signing in.

If sign-in succeeds within that window, refresh the account before finishing. If it is still pending when the window ends, finish the report with that account's last verified figures and date. Each successful check updates its account's baseline independently, and carried-forward figures keep their prior baseline.
