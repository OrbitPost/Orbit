# Chart and calendar libraries for Orbit

Research date 2026-11-19. Package versions and peer ranges come from the npm registry. Feature and integration judgments come from maintainer documentation and tagged source. The acceptance checks below remain open in Orbit's React 19.3.1, TypeScript 7.0.2, Vite 8.3.8, and Electron 45.3.4 renderer. [Desktop stack](../adr/0009-select-orbit-desktop-development-stack.md)

## Home charts

Home shows the latest numeric total, the observation date or reporting period, and any comparable change. Orbit should construct each series from comparable verified observations and keep the originating report ID on every point. A carried-forward value keeps its old verification date and adds no point. The same series can drive the chart and a **Report history** list of date, value, and report link. [Product brief](../../PRODUCT.md) · [ADR 0007](../adr/0007-chart-verified-metric-totals-from-saved-reports.md)

| Candidate | Evidence and fit |
| --- | --- |
| **Recharts 3.11.0** | MIT, React and React DOM 19 peer support, bundled declarations. Use a numeric date axis with formatted ticks for irregular intervals and a custom dot that opens the report on click. The accessibility layer lets arrow keys explore points. In 3.11.0 Enter toggles the keyboard tooltip, so give report history its own native links. The built-in dark theme and CSS variable support let the chart use the workspace's colors. [Package metadata](https://registry.npmjs.org/recharts/3.11.0) · [Axis](https://recharts.github.io/en-US/api/XAxis/) · [Custom dots](https://recharts.github.io/en-US/guide/dataStyles/) · [Keyboard behavior](https://github.com/recharts/recharts/blob/v3.11.0/src/state/keyboardEventsMiddleware.ts) · [Theming](https://recharts.github.io/en-US/guide/theming/) |
| **Chart.js 4.6.1 with react-chartjs-2 5.3.1** | Both MIT with bundled declarations. The wrapper's peers cover React 19 and Chart.js 4. It supplies a React line component and a helper to resolve a canvas click to a dataset point. A linear timestamp axis can use app-formatted labels. The dedicated time scale requires a date library and adapter. Colors are chart options, and a canvas label describes the chart as a whole. Orbit would supply the separate keyboard and screen-reader path to its report links. ## Calendar

Orbit should project its published posts and scheduled destinations into timed events with stable IDs, local details, and status text for automatic, manually prepared, overdue, and verification-needed posts. The same scheduling command should handle edits from the Calendar and chat. Orbit owns media, publication state, and the scheduler. [Product brief](../../PRODUCT.md) · [ADR 0002](../adr/0002-schedule-posts-for-explicit-destinations.md) · [ADR 0004](../adr/0004-preserve-scheduled-content-and-verify-publishing.md)

| Candidate | Evidence and fit |
| --- | --- |
| **FullCalendar Standard 7.1.5** | MIT with React and React DOM 19 peer support and bundled declarations. Month, week, list, and day/time click support are Standard. Resource timeline and vertical resource views are Premium. Named timezone rendering is built in through the Temporal peer. `eventInteractive` makes post events focusable, and render hooks can add readable status text. Themes provide dark palettes and scoped CSS overrides. Orbit would supply a keyboard-operable scheduling form. [React integration](https://fullcalendar.io/docs/react) · [Plugins](https://fullcalendar.io/docs/plugin-index) · [License](https://fullcalendar.io/license) · [Time zones](https://fullcalendar.io/docs/timeZone) · [Event accessibility](https://fullcalendar.io/docs/eventInteractive) · [Event hooks](https://fullcalendar.io/docs/event-render-hooks) · [Palettes](https://fullcalendar.io/docs/color-palettes) |
| **React Big Calendar 1.20.0 with Luxon 3.7.2** | MIT with React and React DOM 19 peer support. Supplies month, week, agenda, selection callbacks, CSS, and Sass variables. Its Luxon example sets `Settings.defaultZone`, which affects that Luxon instance across the renderer. The published Luxon localizer uses that default in formatting and date arithmetic. Default time-grid events receive focus and forward key events. The month event wrapper and agenda cells need additional focus and activation work. TypeScript uses separate community declarations. For FullCalendar v7, import `daygrid`, `timegrid`, and `interaction` from `@fullcalendar/react` subpaths. Add `skeleton.css` and a theme plugin with its theme and palette CSS from that same package. Scope `colorScheme="dark"` to the calendar so it fits the near-black workspace center beside the light glass panels. `dateClick` needs the interaction plugin. `eventClick` can open Orbit's post details. [Desktop stack](../adr/0009-select-orbit-desktop-development-stack.md) · [React setup](https://fullcalendar.io/docs/react#installation) · [Plugin index](https://fullcalendar.io/docs/plugin-index) · [Palettes](https://fullcalendar.io/docs/color-palettes) · [Event click](https://fullcalendar.io/docs/eventClick)

Set `timeZone="Asia/Bangkok"` and feed timed events offset-bearing ISO strings or epoch milliseconds. A timed `dateClick` returns an offset-bearing `dateStr` and an instant as `Date`. Use its instant or format it explicitly in Bangkok. A month cell yields a date-only `dateStr`. Prefill that calendar date, collect a Bangkok wall-clock time in the scheduling form, and convert the completed value to a UTC instant for storage. FullCalendar v7 resolves named zones through Temporal. For named zones, v6's plugin-free UTC coercion can discard supplied offsets. ## Acceptance checks

- Build both surfaces with Orbit's selected React, TypeScript, and Vite versions. Check keyboard focus and text contrast in Electron with both side panels open.
- Save verified, carried-forward, and noncomparable observations. Confirm the Home total and original date, correct point spacing, and that clicking a point and activating its report link by keyboard open the same saved report. Check that an empty series and a single observation remain readable.
- Under `Asia/Bangkok` and `America/Los_Angeles` host settings, confirm `2026-11-19T17:30:00Z` appears on November 20 at 00:30 Bangkok time. Click the week slot and enter the same date and time in the keyboard-operated scheduling form from the month view. Both paths should save the same UTC instant and restore the same Bangkok date and time after reopening.
- Verify a published post, an automatic schedule, a manually prepared draft, an overdue item, and an item awaiting publication verification. The status and destination should be readable without color, and each event should open the correct details by pointer and keyboard.
